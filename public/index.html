Netlify Server Telegram Bot

The console needs a password

Set CONSOLE_PASSWORD to at least 16 characters in the project's environment variables, then redeploy.

The easiest way is to ask an Agent Run. Start one on this project in the Netlify UI, and give it this prompt:

Generate a secure password for this project's console. Show it to me and help me set it as an environment variable named CONSOLE_PASSWORD, marked as secret. Remind me to save the password somewhere safe, and to publish the changes!
